# Install Latest Node

```bash
npm install
```

# Configure .env file
A sample is provided below:
```bash
HOSTNAME='localhost'
# http://15.206.121.28:3000
# HOSTNAME='localhost'
BACKEND=http://$HOSTNAME:3000
NEXT_PUBLIC_BACKEND_URL=$BACKEND
NEXT_PUBLIC_REPO=Admin
NEXT_PUBLIC_PROJECT_URL='https://www.google.com'
NEXT_PUBLIC_LOGO_URL='/assets/images/logoMain.png'
NEXT_PUBLIC_LOGIN_COVER_IMAGE_URL=''
NEXT_PUBLIC_PRIMARY_COLOR='#009d33'
NEXT_PUBLIC_SECONDARY_COLOR='#101828'
```

# Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
